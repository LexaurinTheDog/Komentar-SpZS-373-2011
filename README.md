# Komentář k zákonu č. 373/2011 Sb., o specifických zdravotních službách

Odborný komentář k **zákonu č. 373/2011 Sb., o specifických zdravotních službách** — sesterskému předpisu zákona o zdravotních službách pro výkony se zvláštními souhlasovými režimy: asistovaná reprodukce, sterilizace, kastrace, změna pohlaví, genetická vyšetření, posudková péče a pracovnělékařské služby, lékařské ozáření, ochranné léčení a záchytná služba.

Konsolidované znění: dokument e-Sbírky `SB-2011-00373_2026-01-01`.
